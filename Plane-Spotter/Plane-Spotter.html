Plane Spotter

by Jag Singh

Home : Plane Spotter

Click here to see live flight data and airplane pictures.

The plane spotter is a Python program that uses a software defined radio (SDR) to capture overhead flight data, and a type of AI called the Convolutional Neural Network (CNN) to capture the airplane picture. The data and pictures are stored in a Google Cloud Storage bucket as an html document for viewing.
